# G5 / G6 冻结协议（2026-09-29，任何新分数读取前）

目的：分别检验训练奖励和局部目标选择。正式 E009 不改，不使用已见的 A4。v2/v3 是开发集，新的 v4/v5 只用于通过开发门槛后的单次确认。所有分数仅为 Windows 本地预览。

## G5：训练奖励，唯一变量

- 对照为原 C 混合 PPO E014/E015/E016（种子依次 7101/7102/7103），均为 1,044,480 样本，**原始 PPO 动作**。新模型 E032/E033/E034 使用完全相同的三个种子、场景配比、网络、训练步数、学习率和其余超参数；从头训练，不挑中途检查点。
- 唯一变化：每个智能体训练时，给环境原奖励加 `0.2 × (上一步最近可见目标距离 − 本步最近可见目标距离)`。没有可见目标时距离记 0.6，终局使用终局观测而非自动重置观测；距离截到 0.6。观测和正式评测奖励不改。训练包装器及入口文件 SHA-256 在首次训练前记录在 `outputs/P103/g5-freeze-001.json`。
- v2/v3 各 200 回合，与各自 C 原始 PPO 同题同策略种子对比。需全部完成、模型导出一致性通过；三种子至少两份的 v2/v3 等权分差 > 0，三种子平均等权分差 ≥ +3.00；每套题每组的三种子平均覆盖下降 ≤ 0.005、碰撞上升 ≤ 0.003。否则停止 G5，不看 v4。对照的原始结果只用于差值，不改变门槛。
- 若通过，v4 用 100 个新 basic 和 100 个新 cooperation 场景，每场景重复 2 次。三个种子均与对应 C 原始 PPO 同场景比较。换模需三种子至少两份分差 > 0、平均分差 ≥ +3.00、两组平均覆盖下降 ≤ 0.005、碰撞上升 ≤ 0.003。若未过，不换模。

## G6：局部目标选择，唯一变量

- 固定现有 C 三份权重（E014/E015/E016，训练种子 7101/7102/7103），旧 D 组合策略为成对对照（40% 最近可见目标方向 + 原避让）。新策略只把“每步取最近”改为**目标锁定**：首次见到目标取最近的目标编号；只要仍可见便保持，除非另一目标比当前目标至少近 0.12；当前目标消失才重新取最近。重置时清空锁定。40% 混合、避让、模型权重均不变。
- 在 v2/v3 各 200 回合比较三份权重的旧/新策略。需全部完成；三种子至少两份等权分差 > 0，三种子平均等权分差 ≥ +2.00；每套题每组的三种子平均覆盖下降 ≤ 0.005、碰撞上升 ≤ 0.002。否则停止 G6，不看 v5。
- 若通过，v5 另用 100 个新 basic 和 100 个新 cooperation 场景，每场景重复 2 次；三种子仍与旧 D 组合策略成对比较。换模需至少两份分差 > 0、平均分差 ≥ +2.00、两组平均覆盖下降 ≤ 0.005、碰撞上升 ≤ 0.002。若未过，不换模。

- v4 的场景种子：basic 91000–91099、cooperation 101000–101099，策略随机数 entropy 87541。
- v5 的场景种子：basic 110000–110099、cooperation 120000–120099，策略随机数 entropy 97541。
- 生成器先检查与 public、v2、v3、A4、训练种子及两套新题之间无种子交叉；固定 suite/schedule 文件及 SHA-256。生成后禁止修改题目或筛选门槛。
- 任一训练、预检、导出、评测或指纹核验失败，先修复运行错误；若无法恢复可比性，终止相应线并如实报告。任何未过开发门槛的线不读取其确认场景分数。两条线独立判断，不用一个实验的确认场景调另一个。
- 即使通过确认门槛，也只将候选列为可考虑换模；正式 E009 的切换须重新核对正式目录、许可证、Linux 复验和交付记录。本轮不自动修改正式 E009。
