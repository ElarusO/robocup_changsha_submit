# C 阶段分组弱点诊断（2026-09-26）

比较对象是 B3 的 E011–E013 与 C 的 E014–E016，各自在 **1,044,480** 样本的最终检查点；相同训练种子成对比较，使用相同的开发验证 v2。每组有 50 个场景、每场景两次重复。本策略按当前观测确定性输出动作，两次重复在这里得到相同轨迹，因此分析场景波动时以 **50 个不同场景**为单位。原始逐回合汇总：`../../outputs/P103/c-group-diagnostics-001/summary.json`、`cases.csv`；重点场景重放轨迹：`../../outputs/P103/c-group-replay-001/trajectories.json`。重放的覆盖率与碰撞统计已逐项和正式 `episodes.csv` 核对。

## 1. 7101 的基础覆盖率下降：总体很小，但有具体失败场景

E011→E014 的基础组平均覆盖率从 **0.1060** 降至 **0.1027**，差 **−0.0033**。50 个场景中，混合模型胜 8、负 8、相同 34；按场景配对重采样的描述性 95% 区间为 **[−0.016, +0.008]**，跨过 0。因此不能说它在基础组普遍退化。三个固定训练种子的基础覆盖率平均变化反而是 +0.0038，场景区间 [−0.0042, +0.0107]，同样不能证明稳定提高。

**`v2b-02` 是值得追查的具体场景。**三个混合模型在此场景都比对应的基础训练模型覆盖得少，场景平均覆盖率差依次为 **−0.20、−0.1333、−0.0667**。重放发现：B3 模型会在后半回合同时覆盖目标 0 和目标 2，C 模型只覆盖目标 0；六份模型在此场景都没有机器人碰撞。目标 2 的覆盖半径为 0.15。到第 10 步，离目标 2 最近的机器人距离，在 B3 三种子中约为 0.105、0.080、0.151，在 C 中约为 0.241、0.169、0.230。它表明混合模型在这个均匀布局下**没有充分接近第二个目标**；当前记录还不足以推断这种行为在其他类似布局中的频率。

## 2. 7101 的协作碰撞：集中在两个场景

E011→E014 的协作组平均碰撞率从 **0** 升至 **0.008**。这不是“0.8% 的回合碰撞”，而是把每一步参与碰撞的机器人比例再跨回合平均。按官方统计定义，两台机器人中心距离小于半径之和 0.10 即记碰撞；本次上升对应 **12 个“机器人对×时间步”记录**，发生在 4 个评测回合。由于两次重复轨迹相同，实际只有 **2 个不同场景**：`v2c-07` 与 `v2c-09`，各出现 3 个连续碰撞步、重复两次。按 50 个场景配对重采样，7101 碰撞率差的描述性区间为 **[0, +0.020]**；这提示风险，但不能证明所有协作场景的碰撞率都会增加。

- **`v2c-09`：有跨种子重复的风险。**三个 C 模型在这里都出现 0 号与 2 号机器人连续 3 步接触；两个 B3 模型没有碰撞，另一个 B3 模型也在这里碰撞。C 模型接触时，两台机器人离同一个目标 1 最近，目标也处于 0.6 的可见范围内。这与“靠近同一个目标时没有拉开间距”的现象一致，但不能仅凭位置确定网络的内部决策。
- **`v2c-07`：主要属于 7101 的局部问题。**只有 E014 在这个场景的第 6–8 步出现同一对机器人接触；另外两个 C 模型在此场景没有接触。两台机器人初始间距约 0.148，较接近 0.10 的接触阈值；碰撞时最近目标仍在约 0.73–0.79 远处，超出 0.6 的可见范围。因此这里不能解释为“看见并争抢同一个目标”，更像是近距离行驶路径冲突，仍需看动作与速度轨迹确认。

全部三个训练种子合起来，C 相对 B3 的协作覆盖率平均 **+0.0098**，按场景重采样区间约 **[+0.0040, +0.0162]**；协作碰撞率平均 **+0.0022**，区间约 **[−0.0027, +0.0089]**。覆盖改善更一致，碰撞增多仍是待确认的局部风险。

## 3. 为什么总分仍提高

此套件的每步团队奖励是“覆盖率 − 0.2×碰撞率”，两组等权后总分为 `500×(基础组平均奖励 + 协作组平均奖励)`。对种子 7101，C 相对 B3 的分差可拆成：基础覆盖 **−1.67 分**、基础碰撞 **−0.27 分**、协作覆盖 **+5.00 分**、协作碰撞 **−0.80 分**，合计约 **+2.27 分**。因此总分改善掩盖了基础组的局部漏目标和协作碰撞；机器人间距值得单独监控。

## 4. 接下来怎样改进

1. **先做轨迹诊断。**对 `v2b-02` 及其他基础组失分场景，记录每步目标可见性、机器人到每个目标的距离、动作方向及是否重复追同一个目标；按相同几何特征在现有开发集找更多场景验证，避免只针对一个编号调参。
2. **单列近距离安全指标。**在 `v2c-09`、`v2c-07` 和其他协作场景记录机器人最小距离、连续接触步数、碰撞时可见的队友与目标，以及多台机器人是否靠近同一目标。观测本身提供可见队友的位置和速度，但当前 PPO 是否充分利用这些信息尚未证实。
3. **保持成对评测。**如果下一阶段尝试更强的避让训练或动作规则，仍用同一批开发场景和至少三个训练种子，要求总分、基础/协作覆盖与碰撞一起汇报。先做单因素对照，不因这两个场景就直接更换正式提交模型。

这些区间只反映固定三种训练种子下的开发场景波动，没有覆盖更多训练种子或组织方未见场景。A4 最终确认集本次未使用；当前正式提交仍是 E009。
