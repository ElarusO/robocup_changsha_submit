# H3：晚进入与未进入的诊断结果

2026-09-30，P103。**发现了值得继续验证的方向：在较远处更早、更有力地追赶目标。固定参考通过开发门槛，但还没有独立确认，正式模型仍是 E009。**

## 1. 这次做了什么

按事前 [协议](H3_PURSUIT_PROTOCOL.md)，从旧组合策略的600条轨迹筛出1088个“晚进入/可见但从未进入”的目标时间步，去重后是585个模型×场景×目标，来自152个不同场景。三份模型来自训练种子7101、7102、7103，本轮没有训练。

逐步检查看到什么、选了哪个目标、动作朝向、推进余量、避让是否削弱朝目标的动作。再运行固定规则：最近可见目标距离大于覆盖半径+0.05时，按当前目标方向加大各轴推进；靠近后恢复旧组合，原避让始终保留。规则只读机器人自己的合法当前观测，不读全局状态或真实未来。

所有600条场景都运行，包含原本好的场景。每条旧轨迹覆盖/碰撞都对齐历史两次重复；重建观测的动作也对齐旧轨迹。新旧目标轨迹逐字节一致，动作合法，输入摘要未变，正式E009四份文件与冻结版一致。

## 2. 先解释为什么必须早点动

动作不能立刻改变当前位置：本环境先按旧速度更新位置，再按新动作更新速度。决策步s的动作最早影响s+2计分位置。因此看到即将漏覆盖，再临时加力，可能已经来不及。

1088个缺口中，**939个（86.3%）在最后还来得及影响该计分步的决策状态，已被条件动力学包络排除**。意思是：沿旧轨迹走到那时，再怎么改该步动作也补不回那一分，需要更早改变轨迹。包络是包含接触力的乐观范围；落在范围内仍不证明能追上。这不是939个独立场景，也不是从初始状态就不可能。

更早可见且尚未被包络排除的决策里，出现以下现象：

| 重叠现象 | 涉及缺口数 | 含最近目标决策的缺口数 |
| --- | ---: | ---: |
| 最终动作有背离该目标的分量 | 142 | 86 |
| 避让使朝目标投影减少超过0.05 | 35 | 26 |
| 固定等比例大推力相对避让前动作有超过0.1的推进余量 | 580 | 384 |

这些数不能相加，也不能直接叫作失分原因。某个目标并非最近目标时，朝别处走可能是合理分工；投影余量也不保证最终得分。这里的“大推力”是固定等比例参考，不是任意方向动作的数学最大投影。

## 3. 固定追赶参考的实测结果

以下为官方环境中的**离线本地重放分数**：用官方最大匹配指标和原套件组均值计算，三模型分别比较同场景旧组合。不是 evaluate_one 完整沙箱评测，也不是比赛认可分数。

| 模型 | 旧组合平均分 | 追赶参考平均分 | 变化 | 改善/恶化/持平场景 |
| --- | ---: | ---: | ---: | --- |
| E014 | 139.37 | 148.30 | +8.93 | 36 / 13 / 151 |
| E015 | 142.50 | 149.17 | +6.67 | 37 / 15 / 148 |
| E016 | 139.27 | 148.20 | +8.93 | 34 / 12 / 154 |
| 三模型平均 | 140.38 | 148.56 | **+8.18** | 合计107 / 40 / 453 |

全体1800个模型×场景×目标中，109个首次计分进入提前或从未进入变为进入，49个延后或丢失，其余1642个不变。固定筛选的585个目标中，109个提前、34个延后或丢失、442个不变。几何覆盖时间步净增140，具体得分仍按最大匹配计算。

基本组三模型平均覆盖率+0.01133、碰撞率+0.000444；协作组覆盖率+0.00511、碰撞率不变。两组均通过事前安全门槛。三模型分别36、36、37个首次进入提前，满足至少两个模型各5个的门槛。平均+2分、两模型提升、安全与提前进入四个开发条件全部通过。

**改善说明这种合法规则确实能改变早期轨迹并提前覆盖，不能归功于目标预测。**参考完全没有预测目标运动；本轮也没有做强追赶与预测的组合。轨迹改变后后续最近目标选择会跟着变化，不能把所有收益都归为单步推力变化。

## 4. 两个改善案例、两个退步案例

覆盖半径均为0.15，计分从第1步开始。

- **E016 / v2b-02 / 目标0：** 旧策略第5步距离0.15285，差一点覆盖，第6步才进入；参考第5步0.14862，提前一步，增加一个几何覆盖时间步。这是之前目标混合使E016漏掉的已知案例。
- **E015 / v2b-04 / 目标1：** 旧策略整局未进入，第10步还距0.18901；参考第7步进入，最后距离0.07277，增加4个几何覆盖时间步。同场景目标0也从第7步提前至第6步。
- **E015 / v3b-08 / 目标0：** 旧策略第5步进入并保持；参考第6步才进入，随后第7、8步出圈，净少3个几何覆盖时间步，场景得分下降100分。这说明大推力切回旧控制后，也可能形成不合适的速度或路径；具体责任需要下一轮检查，不能凭距离直接认定过冲。
- **E014 / v2c-41：** 目标1从第8步延后到第9步，目标2从第5步延后到第6步，净少两个几何覆盖时间步，场景得分下降66.67分。追赶参考仍存在真实退步，不能宣称全面变好。

## 5. 结论与下一步

H3诊断已完成。与H2A/H2B主要改善进入后的保持不同，这轮找到了实际提前进入的证据。**下一项应将本轮完全固定的参考做成候选，先完成正式入口预检和六次完整开发评测，再做新场景独立确认。**

建议下一轮单独写定协议：至少三训练种子；旧组合为主对照，H2B为额外对照以防忽略已知保持收益；开发平均至少+2、至少两模型提升、各组覆盖/碰撞安全门槛，独立确认要求配对置信区间下界大于0。新确认场景在看候选分数前固定。v8已见不能充当新的确认；本轮v4—v7仍未评分。

第一轮先验证原封不动的追赶参考。以后若需改善切换/制动，另写定单因素协议再调整；预测组合也作为独立后续实验。本轮的1088缺口、152场景和上述案例都已见，不能再当作未见确认数据。
