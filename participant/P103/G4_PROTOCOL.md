日期：2026-09-29。G1–G3 后处理没有通过各自的开发门槛。本轮只检验现有 C 混合训练在 1,044,480 样本之后是否继续改善；不改变网络、环境、奖励、学习率或探索系数，不改正式 E009，不运行 A4。

## 冻结训练配置

- 仍从头训练，沿用 C 的 `mixed-basic0-coop0`：4 个环境副本中 2 个 basic-0、2 个 coop-0；原训练种子 **7101、7102、7103**，对应新实验 E029–E031。
- Python 3.12、stable-baselines3 2.9.0、supersuit 3.11.0；`train.py` SHA-256 `3d8506de922bd5662ed7f0006aeaec68151e7ed57e16aab3ca5c23c58abbd578`，`mixed_env.py` SHA-256 `2336814f59fec9d09a0f9a61709c75bcfc860d87dc3d406cf00f23c9cf000aa9`。
- 请求 2,000,000 样本，`curve_points=20`；每段 104,448 样本，预计实际 **2,088,960** 样本。预先保存 1,044,480、1,566,720、2,088,960 检查点；方法比较只使用三个种子的共同最终位置，不从中挑最好检查点。
- 其余同 C：学习率 0.0001、`gamma=0.99`、`n_steps=512`、`batch_size=256`、`ent_coef=0`，网络 104→64→64→2，观测归一化。每个训练和导出使用新的 `outputs/P103/train-E029` 至 E031、`post-E029` 至 E031；导出不激活正式目录。
- 首个检查点与旧 C 对应种子的 1,044,480 样本模型及归一化统计逐数组比较。若不一致，明确记录可比性限制，不声称唯一变化是预算。

## 开发比较与停止门槛

旧 C 原始 PPO（无动作后处理）的 E014、E015、E016 最终模型为成对对照。v2 对照文件依次为 `outputs/P103/c-v2-E014-1044480/result.json`、E015、E016 对应目录；v3 对照为 `outputs/P103/d-v3-E014-base/result.json`、E015、E016 对应目录。三份新最终模型只用原始 PPO 动作，在 v2/v3 同题、同种子安排上预检并评测；每次应为 `status=ok`、200/200 回合，核对模型摘要和题目指纹。分组报告覆盖、碰撞和总分。

只有同时满足：三个种子中至少两个在 v2/v3 等权分数上相对各自 C 基线提高；三个种子的等权平均分差至少 **+5.00**；在每套题、每个分组上三种子平均覆盖率下降不超过 **0.005**、碰撞率上升不超过 **0.005**，才进入新场景确认。未满足则停止 G4，不挑单一种子或中间检查点作为“方法成功”。v2/v3 已用于开发；新场景和换模门槛要在看新场景成绩前写定。所有运行产物为本地预览，不是组织方分数。
