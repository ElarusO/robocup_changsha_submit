# H5：远距离路线诊断方法（分析前固定）

日期：2026-10-03。目的：解释 H4 同一 E015 模型、已见 v10 场景中，H3 追赶控制为什么在 14 个场景退步。**本轮只诊断，不搜索参数、不训练、不产生独立确认分数、不更换正式 E015＋H3。**

## 固定输入

- 使用 H4 两份冻结策略：E015＋H3 与 E015＋旧组合；模型、v10 配置和结果路径沿用 `H4_DIAGNOSTIC_PROTOCOL.md`。
- 使用 `outputs/P103/h4-v10-trace-001/summary.json` 与 14 份轨迹；其退步场景和漏覆盖目标时间步清单已经由 H4 确定。
- 只读官方环境、协议和指标来核对轨迹。所有新结果写入 `outputs/P103/h5-far-route-001/`。

## 逐个漏覆盖目标时间步记录什么

1. 旧组合实际覆盖该目标的机器人，以及 H3 离它最近的机器人；二者是否相同。不要默认“最近者”就是原本应负责的机器人。
2. 在最后一个能影响该计分时刻的位置的决策步（计分步 `s` 对应决策 `s-2`），记录两种策略下的目标选择、目标距离、到目标的相对速度、朝向目标的动作投影和 H3 远距分支状态。
3. 对旧组合覆盖机器人的整段历史，记录 H3 与旧组合第一次动作不同的步、第一次机器人位置不同的步、两者各自的目标选择。判断路线差异是否早于最后可补救的决策。
4. 用保存的动作和位置重新核对两种策略轨迹。若核对失败，停止分析，不使用该份记录。

上述标签是**可重叠的轨迹特征**，不是自动判定的单一因果：目标选择变化、旧组合负责机器人改变、H3 更远、H3 朝目标闭合速度更低、避让后推进减弱。只在多个独立场景出现同一特征、且逐步轨迹与动作时序一致时，才提出下一轮候选假设。单个失分时间步、仅有动作夹角、或同一场景连续两步，不足以证明一般规律。

## 停止与后续

- 输出每场景的机器可复核记录和简明报告，写明分母、重叠关系与无法归因的部分。
- 本轮不打开 v11。若将来开发新控制规则，先单独固定规则、对照、至少三模型开发门槛，以及全新的确认场景；v10 已见，只能继续用于机制诊断。
- 若没有明确且重复的可修复原因，保留正式 E015＋H3，把时间留给交付。

## 补充：进步场景作对照（在读取该组逐步轨迹前固定）

失分场景的初步分析发现：多个案例在第 0 步两种动作已不同，且旧组合动作对失分目标的起始投影更大。为避免只挑退步案例造成偏见，再对 H4 配对结果中 **H3 净进步的全部 40 个 v10 场景**做相同重放。逐一找出 H3 覆盖而旧组合未覆盖的目标时间步，取 H3 实际覆盖机器人，计算同一机器人在第 0 步朝该目标当前位置的动作投影、是否初始选中该目标、以及第 2 步距离差。按“目标时间步”和“不同场景”分别计数，允许同一场景有多个事件；不只抽选示例。该补充仍属于已见 v10 诊断，不产生独立验证结论或候选参数。
