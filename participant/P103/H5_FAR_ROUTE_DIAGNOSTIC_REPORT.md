# H5：远距离路线诊断（2026-10-03）

## 结论先说

H4 的 14 个退步场景，主要线索不是“快到目标时刹不住”，也不是频繁选错机器人或避让。更常见的是：**第 0 步就把旧组合中更能朝目标推进的动作换成了 H3 的等比例追赶动作，导致第 2 步起略微落后；10 步短回合内，部分目标刚好差一点没进覆盖圈。**

这是在已见 v10 上的**机制证据，不是因果定论或新方法成绩**。H3 在同一 v10 的总分仍高于旧组合 9.80 分，正式 E015＋H3 保持不变。本轮没有训练、调阈值、生成或读取 v11、换模、提交或推送。

## 用了什么，怎么核对

- 事前方法见 [H5 协议](H5_FAR_ROUTE_DIAGNOSTIC_PROTOCOL.md)。只用 H4 冻结的同一 E015 权重、旧组合与 H3 两种控制，以及此前已评分的 v10 场景。
- 对 14 个 H3 退步场景、15 个“旧组合覆盖而 H3 未覆盖”的**目标计分时间步**，逐个核对机器人、目标、动作和轨迹。14 场景重新运行官方环境，机器人位置、速度、动作和目标位置与 H4 保存的轨迹逐数组相同。
- 为避免只挑退步，另外重放 H3 **全部 40 个净进步场景**；两种控制的重放分数均与此前完整评测逐场景对齐。进步场景里 38 个有 H3 独有的几何覆盖时间步，合计 73 个。另 2 个净进步场景没有这种独有几何覆盖，不能拿它们做起步动作比较。
- “动作投影”指动作在当前目标方向上的有效分量；数值越大，**这一步**朝目标方向的推力越大。它不等于整局分数。官方动力学先用旧速度移动，再用当前动作改速度，所以第 0 步动作最早让第 2 步位置不同。

## 退步场景的共同现象

| 观察 | 目标计分时间步 | 不同场景 | 解释 |
| --- | ---: | ---: | --- |
| H3 和旧组合的相关机器人第 0 步动作已不同，第 2 步位置已不同 | 15/15 | 14/14 | 差异在远处形成，时间上早于漏覆盖 |
| 第 0 步旧组合朝该目标的动作投影比 H3 更大 | 12/15 | 12/14 | H3 的“追赶”不一定比原动作推得更足 |
| 第 2 步 H3 到该目标的距离更大 | 14/15 | 13/14 | 早期劣势已体现在位置上 |
| 最后可补救的决策时，H3 相关机器人更远、朝目标的相对接近速度更低 | 各 14/15 | 各 13/14 | 早期差异延续至计分前 |
| 该机器人第 0 步选中了后来漏掉的目标 | 14/15 | 13/14 | 大多不是一开始追了别的目标 |
| 最后可补救的决策时，两种控制都选中该目标 | 15/15 | 14/14 | 当时的目标选择相同 |
| 旧组合覆盖机器人也正是 H3 离该目标最近的机器人 | 15/15 | 14/14 | 没发现换机器人负责导致的这一组损失 |
| H3 起步避让使朝目标投影降低超过 0.05；最后决策发生此情况 | 0/15；0/15 | 0/14；0/14 | 这组案例不支持“避让压低追赶”为主要原因 |

H3 的远距规则把目标方向向量除以**最大轴的绝对值**：较大的动作分量变成 1，另一轴保持比例。这叫“按原方向等比例放大”，**不是**在每个轴都允许 `[-1,1]` 时对目标投影的数学最大值。旧组合动作在部分起点的两个轴上恰好投影更大，因此替换成 H3 后反而减小了有效推进。此解释与第 0 步相同起点、相同目标、动作投影差和第 2 步距离差一致；但它还没有经过单因素干预和新场景确认。

示例：`v10c-007` 的目标 0，第 0 步 H3/旧组合朝该目标的动作投影为 **1.044/1.148**；第 2 步 H3 比旧组合远约 **0.0013**；第 10 步旧组合距目标 **0.1200**，H3 距 **0.1589**，覆盖半径为 **0.15**。这些小距离差足以跨过离散计分边界。`v10b-023` 是例外：起步时相关机器人先追目标 2，后来的漏失目标是 1；不能把它解释为“起步同目标下 H3 推力较弱”。

## 用进步场景检查这个解释

| 相同检查 | H3 独有覆盖的时间步 | 涉及不同场景 |
| --- | ---: | ---: |
| 起步 H3 就选择该目标 | 73/73 | 38/38 |
| 起步 H3 朝该目标的动作投影大于旧组合 | 64/73 | 31/38 |
| 第 2 步 H3 比旧组合更接近该目标 | 62/73 | 29/38 |

退步与进步的方向相反，支持“**起步有效推进影响短回合能否首次进入**”这一线索。这里按目标计分时间步和不同场景同时列分母；同一场景连续覆盖多个时间步并不是多个独立场景。只挑净进步/净退步场景作对比也会带来选择偏差，因此这些比例不能直接当作新规则成功概率或统计显著性。

离线看未来目标位置时，旧组合在 14/15 个退步时间步的第 0 步动作，对第 4 步目标位置的投影更大。但它对**当前**目标位置也常更大，所以本轮不能据此声称旧策略会预测目标运动，或需要再做预测规则。

## 下一步与停止决定

本轮只形成一个值得单独测试的假设：在远距分支里，**不要覆盖掉原来朝已选目标推进更强的合法动作**；其余模型、目标选择与避让保持固定。G1 曾在旧组合基线上试过类似“保留好动作”，未过 +2 分开发门槛，不能把这次诊断当成已验证的新方案。若继续做，应先写定唯一规则、固定三份模型、开发门槛和全新确认场景；在 v10 上调条件或按这些 14 场景挑参数会造成重复使用数据。
